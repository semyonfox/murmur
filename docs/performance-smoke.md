# Linux native and inference smoke

Tested 26 September 2026 on the CachyOS PC (`7.2.6-1-cachyos`) with a Ryzen 5 5600G, an RX 6600 XT (RADV), and an active Hyprland session. These are small synthetic checks, not representative quality or latency benchmarks.

The desktop frontend built with pnpm. The Rust host passed `cargo check --locked`, `cargo build --locked`, a production `pnpm tauri build --no-bundle --ci`, and all 311 `cargo test --locked --lib` tests using the configured Vulkan backend. The PC had GTK, WebKitGTK, ALSA, D-Bus, GTK layer-shell, Vulkan and shader compiler dependencies. SPIR-V Headers were absent from system packages, so the build used a copy in the user's cache via `CMAKE_PREFIX_PATH` and `CPATH`; no system package was installed. The stripped release executable is 46,971,936 bytes; the staged `transcribe-libs/` directory adds about 73 MB. Running it directly needs those libraries on `LD_LIBRARY_PATH` and the host GUI libraries. It is not a portable release bundle.

The GUI was launched briefly under Hyprland 0.56.2 with isolated test data and no tray. Before the window adjustment, `hyprctl clients -j` reported Murmur as tiled at 1705×1376. After the native Hyprland handling was added and rebuilt, debug, release and patched AppImage launches reported the settings window as floating at 680×570, centered on the active monitor. The AppImage was a native Wayland client (`xwayland: false`); the development server was stopped. The test did not start microphone capture or display the recording indicator, so it does not verify the layer-shell overlay, shortcut or text insertion path.

`--list-devices` identified the RX 6600 XT as `Vulkan0` and the Ryzen CPU as `CPU`. A 16 kHz mono, 3.649875-second WAV was generated with `espeak-ng` and `ffmpeg` saying “The quick brown fox jumps over the lazy dog.” The model was `handy-computer/whisper-tiny.en-gguf/whisper-tiny.en-Q8_0.gguf` (45,904,544 bytes, SHA-256 `e8c9b73c06344307d8b346e07fbe93dd88d894627854bcff31523f1ce44394fa`), downloaded to isolated test data and verified against the bundled catalog. No microphone input, personal recording, or API key was used.

| Vulkan, first process                |      71 ms |              301 ms | “The quick brown fox jump over the lazy dog.” |

The warm Vulkan best was about 60× the audio duration; the CPU best was about 18×. These timings cover the model transcription call, not microphone startup, VAD, cleanup, text insertion, or total shortcut-to-paste time. The first Vulkan run was slower than later runs, and even this clean synthetic sentence lost the final “s” in “jumps.” Test real speech, accents, noise, cold starts, longer models and end-to-end latency before selecting a default or making quality claims.

A separate 2.785-second synthetic WAV ran through the production executable with the same installed model and Vulkan device. The model load took 293 ms; three transcription calls took 129, 48 and 49 ms and returned the same wording. This is a second smoke test, not a controlled debug-versus-release comparison. The CLI's `--transcribe-file` mode opens no app window, but still initializes Tauri's GTK backend and requires an available display session; an SSH run without Wayland display variables failed at GTK initialization.

The first AppImage bundle failed because the old `linuxdeploy` strip tool could not read `.relr.dyn` sections in CachyOS libraries. `NO_STRIP=1` let it finish, but its generated GTK hook forced `GDK_BACKEND=x11`. The `pnpm run bundle:linux-wayland` recipe then passed: its [repack step](../apps/desktop/scripts/repack-wayland-appimage.sh) removed that line and produced a 217,033,208-byte AppImage (SHA-256 `6bfe4d74779937ce51909f75e699de8bf7e646d4ad47fa6f0a39367604ea9675`). That earlier file opened under native Wayland and, without an external `LD_LIBRARY_PATH`, transcribed the 2.785-second test clip on `Vulkan0` in 163, 47 and 49 ms after a 94 ms model load. An explicit X11 backend also listed models successfully.

The later shortcut test caught two separate faults. Tauri's Linux global-hotkey backend listened through X11 and missed native Wayland key presses; an evdev listener fixed the press/release path. The first new AppImage then started microphone capture but crashed while loading Canary because its bundled `libtranscribe` had an unresolved `cblas_sgemm` symbol. The [Cargo configuration](../apps/desktop/.cargo/config.toml) now disables the host decoder's external system BLAS link, and the AppImage repack step rejects a transcribe library that still has an unresolved CBLAS reference.

The rebuilt AppImage is 214,977,016 bytes, SHA-256 `c9d05a8b37854bc6cd28cb9316d11f5b6c4179ec96a2ec7de9ada2dd46884929`. Its bundled Whisper Tiny model transcribed the same 2.785-second synthetic WAV without an external library path: Vulkan took 62 and 47 ms after a 96 ms load; CPU took 194 and 189 ms after a 43 ms load. Both returned “The quick brown fox jump over the lazy dog.” These are short-clip smoke times, not end-to-end dictation latency.

In an isolated test profile on Hyprland 0.56.2, the rebuilt AppImage opened a native Wayland (`xwayland: false`) floating 680×570 settings window. A virtual `Ctrl+Shift+J` key press through `ydotool` reached the nonblocking evdev shortcut manager, initialized the microphone stream in 93 ms, loaded the cached Canary model on Vulkan, and created a `gtk-layer-shell` recording indicator. Releasing the keys removed that layer surface. The app stayed running until the 55-second test timeout; it did not crash. This verifies shortcut delivery, microphone startup and indicator lifetime on this machine, but not spoken transcription, clipboard insertion, or behavior on other compositors. Nonblocking shortcuts also pass through to the focused application, so conflicting keybindings remain possible.

After the BLAS change, `cargo test --locked --lib` passed all 318 tests on the PC, including a check that the benchmark prompt matches the app's default cleanup prompt exactly. The frontend lint, formatting, translation and model-language checks passed; the research workspace check and Python cost-model tests passed separately.
