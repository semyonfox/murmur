# Product repository audit

Research date: 26 September 2026. Revisions come from [sources.lock.json](../../research/sources.lock.json). This is a source inspection of four pinned checkouts, including tracked-file inventory, license files, implementation paths and relevant tests. It is not a line-by-line review of every file. No upstream application, installer, test suite, separate model downloader or build was run. Runtime quality, store acceptance, latency, accuracy and compositor behavior remain untested.

The strongest reference here is OpenWhispr for permissively licensed product behavior. FreeFlow is the better focused reference for cleanup rules. Epicenter has useful service boundaries and an actual hosted billing implementation, but its current license is AGPL. VoiceInk is a macOS implementation with useful model and statistics designs, under GPL. None establishes the required five-platform experience by itself.

## OpenWhispr

The checkout has 2,569 tracked files. Its desktop app is Electron with React, TypeScript and JavaScript, not Tauri. The build scripts package Linux, Windows and macOS and fetch several native helpers and model runtimes. It is substantially larger than a minimal dictation app. [Desktop package](https://github.com/OpenWhispr/openwhispr/blob/8d294236840663f6fbf38b00a4845cfb6f14bc17/package.json), [MIT license](https://github.com/OpenWhispr/openwhispr/blob/8d294236840663f6fbf38b00a4845cfb6f14bc17/LICENSE).

### Provider and cleanup boundaries

`transcriptionRoute.ts` is a shared resolver for batch dictation, retry and uploads. Its result distinguishes local execution, direct HTTP, provider-specific proxies, managed Azure and explicit errors. Routes carry a credential reference rather than the credential itself. It guards Deepgram and AssemblyAI as streaming-only in this implementation, preventing an unsupported batch selection from falling through to an unrelated provider. This is worth borrowing as a design: provider capabilities must shape routing, and an unavailable route must fail explicitly. [Route types and resolver](https://github.com/OpenWhispr/openwhispr/blob/8d294236840663f6fbf38b00a4845cfb6f14bc17/src/helpers/transcriptionRoute.ts).

Cleanup has its own provider configuration. `ReasoningService.ts` wraps a default cleanup transcript separately from the system instructions and validates cleanup output. The text-provider factory distinguishes OpenAI, Groq, Anthropic, Gemini, OpenRouter, custom endpoints and a local OpenAI-compatible server. Custom and OpenRouter endpoints use Chat Completions explicitly. Local cleanup starts a packaged `llama-server` through `modelManagerBridge.js`, including context sizing and model lifecycle management. A configurable endpoint alone would be much less work than adopting this whole lifecycle. [Cleanup execution](https://github.com/OpenWhispr/openwhispr/blob/8d294236840663f6fbf38b00a4845cfb6f14bc17/src/services/ReasoningService.ts), [provider factory](https://github.com/OpenWhispr/openwhispr/blob/8d294236840663f6fbf38b00a4845cfb6f14bc17/src/services/ai/providers.ts), [local model lifecycle](https://github.com/OpenWhispr/openwhispr/blob/8d294236840663f6fbf38b00a4845cfb6f14bc17/src/helpers/modelManagerBridge.js).

The default cleanup prompt preserves dictated questions and commands as content, removes filler and false starts, resolves self-corrections, handles spoken punctuation and keeps technical terms. A separate prompt performs explicitly requested generative actions. That separation matters: ordinary dictation must never start answering the words being dictated. Custom vocabulary is appended as spelling guidance. These are prompt instructions, not proof that a model obeys them. Evaluate adversarial commands, code identifiers, names, negation and numbers before using a model by default. [Prompt definitions](https://github.com/OpenWhispr/openwhispr/blob/8d294236840663f6fbf38b00a4845cfb6f14bc17/src/locales/en/prompts.json), [prompt registry](https://github.com/OpenWhispr/openwhispr/blob/8d294236840663f6fbf38b00a4845cfb6f14bc17/src/config/prompts/registry.ts).

### Linux integration

The app detects GNOME, KDE, Sway, Hyprland and other wlroots sessions. Its hotkey manager has compositor-specific paths, including GNOME settings, KDE KGlobalAccel and Hyprland bindings. Hyprland integration uses `hyprctl`, a D-Bus callback and managed configuration files. It can add a source/load directive to the user's main Hyprland configuration. Useful reference material, but Murmur should make persistent configuration edits visible, scoped and reversible. [Session detection](https://github.com/OpenWhispr/openwhispr/blob/8d294236840663f6fbf38b00a4845cfb6f14bc17/src/helpers/linuxSession.js), [hotkey routing](https://github.com/OpenWhispr/openwhispr/blob/8d294236840663f6fbf38b00a4845cfb6f14bc17/src/helpers/hotkeyManager.js), [Hyprland implementation](https://github.com/OpenWhispr/openwhispr/blob/8d294236840663f6fbf38b00a4845cfb6f14bc17/src/helpers/hyprlandShortcut.js).

The important limitation is explicit in `xwayland.js`: Linux Wayland sessions default to an X11 Ozone backend unless the user supplies an Ozone override. The recording overlay is a fixed 208 by 120 logical-pixel Electron window with no decorations, no focus and compositor-specific window types. Sway receives a notification type where needed to preserve focus. This is real compatibility work, but it does not demonstrate a native layer-shell overlay or correctness with XWayland disabled. The Linux paste helper uses X11/AT-SPI terminal detection and offers a `/dev/uinput` path, which has permission and packaging consequences. [XWayland policy](https://github.com/OpenWhispr/openwhispr/blob/8d294236840663f6fbf38b00a4845cfb6f14bc17/src/helpers/xwayland.js), [overlay configuration](https://github.com/OpenWhispr/openwhispr/blob/8d294236840663f6fbf38b00a4845cfb6f14bc17/src/helpers/windowConfig.js), [Linux paste helper](https://github.com/OpenWhispr/openwhispr/blob/8d294236840663f6fbf38b00a4845cfb6f14bc17/resources/linux-fast-paste.c).

### History, statistics and managed service

The SQLite layer records raw and processed transcripts and has a separate `analytics_events` table. Events include an ID, local date, word count, spoken duration, provider, model, mode, counting version and sync state. Aggregate WPM is covered words multiplied by 60,000 divided by summed spoken milliseconds. Events without usable duration do not enter that WPM denominator, and the UI can show coverage. Counts support CJK segmentation through `Intl.Segmenter`. This is a better starting point than averaging individual-session WPM. [Persistence](https://github.com/OpenWhispr/openwhispr/blob/8d294236840663f6fbf38b00a4845cfb6f14bc17/src/helpers/database.js), [counting and aggregation](https://github.com/OpenWhispr/openwhispr/blob/8d294236840663f6fbf38b00a4845cfb6f14bc17/src/helpers/analytics.js).

The delivery path handles held-hotkey safety stops by retaining text for recovery, and distinguishes clipboard failure from paste failure. It saves raw text alongside the final text. Borrow those outcomes and recovery affordances; a posted key event does not prove a target editor accepted the text. [Dictation completion and delivery](https://github.com/OpenWhispr/openwhispr/blob/8d294236840663f6fbf38b00a4845cfb6f14bc17/src/hooks/useAudioRecording.js).

The managed-service client handles word allowances, plans, trials, period resets and workspace entitlements. This is a client usage model, not a cost ledger or a deployable billing backend. No corresponding hosted-service implementation was found in this checkout's tracked server/backend paths. Do not mistake the open desktop/mobile clients for an open replacement for the hosted service. [Usage contract and state](https://github.com/OpenWhispr/openwhispr/blob/8d294236840663f6fbf38b00a4845cfb6f14bc17/src/lib/usageStore.ts).

### Mobile findings

The current repository includes an Expo/React Native companion and an actual Swift iOS keyboard extension. The keyboard communicates recording jobs through App Group storage and Darwin notifications; the host native module owns the audio engine. There is substantially more reusable iOS plumbing here than the initial shortlist suggested. [Mobile package](https://github.com/OpenWhispr/openwhispr/blob/8d294236840663f6fbf38b00a4845cfb6f14bc17/openwhispr-mobile/package.json), [keyboard controller](https://github.com/OpenWhispr/openwhispr/blob/8d294236840663f6fbf38b00a4845cfb6f14bc17/openwhispr-mobile/plugins/keyboard-extension/ios/KeyboardViewController.swift), [host recording bridge](https://github.com/OpenWhispr/openwhispr/blob/8d294236840663f6fbf38b00a4845cfb6f14bc17/openwhispr-mobile/modules/app-group-storage/ios/AppGroupStorageModule.swift).

Mobile provider execution validates the selected endpoint, scopes credentials to that endpoint, rejects redirect changes and cancels active work when credentials change. File uploads use a native background transport. These are useful patterns for keys and recordings crossing a mobile lifecycle boundary. [Provider executor](https://github.com/OpenWhispr/openwhispr/blob/8d294236840663f6fbf38b00a4845cfb6f14bc17/openwhispr-mobile/src/services/providers/ProviderExecution.ts), [credential cancellation](https://github.com/OpenWhispr/openwhispr/blob/8d294236840663f6fbf38b00a4845cfb6f14bc17/openwhispr-mobile/src/services/providers/ProviderCredentialScope.ts), [native transport](https://github.com/OpenWhispr/openwhispr/blob/8d294236840663f6fbf38b00a4845cfb6f14bc17/openwhispr-mobile/src/services/providers/NativeProviderTransport.ts).

On-device routing chooses between Whisper and language-compatible Parakeet models. The Parakeet native integration is iOS-specific. More importantly, the ordinary transcription-and-cleanup pipeline returns the raw result immediately when transcription ran locally. Local STT therefore does not imply local cleanup in this mobile path. Murmur needs a deliberate solution for that missing stage. [Local routing](https://github.com/OpenWhispr/openwhispr/blob/8d294236840663f6fbf38b00a4845cfb6f14bc17/openwhispr-mobile/src/services/transcription/localEngine.ts), [cleanup branch](https://github.com/OpenWhispr/openwhispr/blob/8d294236840663f6fbf38b00a4845cfb6f14bc17/openwhispr-mobile/src/lib/transcribeAndCleanup.ts).

The README calls iOS the active release target and says Android native builds and releases are not CI-validated. The AI-model configuration screen gates provider setup to iOS. A tracked-source search found no Android `InputMethodService` or `BIND_INPUT_METHOD` implementation. An Android build script does not establish a system-wide Android dictation keyboard. Treat Android parity as missing, not verified. [Platform caveats](https://github.com/OpenWhispr/openwhispr/blob/8d294236840663f6fbf38b00a4845cfb6f14bc17/openwhispr-mobile/README.md), [platform gating](https://github.com/OpenWhispr/openwhispr/blob/8d294236840663f6fbf38b00a4845cfb6f14bc17/openwhispr-mobile/src/screens/AIModelsScreen.tsx).

Recommendation: borrow provider capability routing, separate analytics events, explicit delivery outcomes and iOS job handoff. Avoid inheriting the full notes, meetings, enterprise and assistant product. Review each copied module for unrelated dependencies and logging of prompts. Do not use its desktop shell as evidence that native Wayland support is solved.

### Follow-up product features

OpenWhispr treats imported audio as a separate notes workflow: users can choose a local file or audio URL, choose an upload provider/model, cancel processing, keep segment timestamps, and export SRT, TXT, JSON or Markdown. Murmur already keeps dictation history, but has no audio-file import. A narrow import-and-transcribe action is more useful to build next than copying OpenWhispr's whole notes workspace. [Upload view](https://github.com/OpenWhispr/openwhispr/blob/8d294236840663f6fbf38b00a4845cfb6f14bc17/src/components/notes/UploadAudioView.tsx), [URL downloader](https://github.com/OpenWhispr/openwhispr/blob/8d294236840663f6fbf38b00a4845cfb6f14bc17/src/helpers/urlAudioDownloader.js).

Its Google Calendar integration shows upcoming meetings and can open a Google Meet, Zoom or Teams link while creating a meeting note. That is more than transcription: OAuth, calendar permissions, attendee context, reminders and a note lifecycle all need product and privacy decisions. Keep it optional and separate from Murmur's core shortcut. [Upcoming meetings](https://github.com/OpenWhispr/openwhispr/blob/8d294236840663f6fbf38b00a4845cfb6f14bc17/src/components/UpcomingMeetings.tsx), [meeting link recognition](https://github.com/OpenWhispr/openwhispr/blob/8d294236840663f6fbf38b00a4845cfb6f14bc17/src/helpers/meetingJoinUrl.js).

OpenWhispr also pauses playing media during a dictation and resumes only media it paused itself when capture ends. Murmur's current toggle mutes system output and restores the previous mute state; playback keeps advancing silently. A true pause/resume option would avoid losing a podcast or video segment. Another useful idea is opt-in learning from corrections after insertion, with an undo action; silent dictionary learning would be too surprising. [Media controller](https://github.com/OpenWhispr/openwhispr/blob/8d294236840663f6fbf38b00a4845cfb6f14bc17/src/helpers/mediaPlayer.js), [recording flow](https://github.com/OpenWhispr/openwhispr/blob/8d294236840663f6fbf38b00a4845cfb6f14bc17/src/hooks/useAudioRecording.js), [settings](https://github.com/OpenWhispr/openwhispr/blob/8d294236840663f6fbf38b00a4845cfb6f14bc17/src/components/SettingsPage.tsx).

Ben Davis's public [V07 repository](https://github.com/davis7dotsh/v07) is [MIT licensed](https://github.com/davis7dotsh/v07/blob/main/LICENSE). It uses a native Swift macOS push-to-talk client and a separate Bun/Fastify inference server that can run on another Mac or Linux host. Audio uploads while the user speaks, and finished takes queue on the server. That client/server split is relevant to Murmur's optional self-hosted model service, but V07 is not a five-platform app and its code has not been imported here.

## FreeFlow

This is a compact 87-file macOS Swift project. Its Makefile builds an AppKit/SwiftUI application and targets macOS. The pinned checkout has no Linux, Windows, iOS or Android host implementation. [Build definition](https://github.com/zachlatta/freeflow/blob/ad5c827b5a324c503d58f948d500fa5d9f90e7d8/Makefile), [MIT license](https://github.com/zachlatta/freeflow/blob/ad5c827b5a324c503d58f948d500fa5d9f90e7d8/LICENSE).

### Cleanup is the useful part

`PostProcessingService.swift` defines conservative cleanup rules with examples for multilingual self-correction, mixed-language preservation, spelling from visible context, paths, flags and identifiers. It treats a dictated request as words to preserve. It also separates selected-text editing into a different contract, where the voice command really is an instruction. A guard checks for outputs that appear to have executed the dictation instead of cleaning it. The service has a deadline, fallback models and explicit empty/invalid-output handling. [Cleanup and command contracts](https://github.com/zachlatta/freeflow/blob/ad5c827b5a324c503d58f948d500fa5d9f90e7d8/Sources/PostProcessingService.swift), [output guard](https://github.com/zachlatta/freeflow/blob/ad5c827b5a324c503d58f948d500fa5d9f90e7d8/Sources/TranscriptTextCore.swift).

The app preserves the raw transcript when ordinary cleanup fails, rather than losing the dictation. Its history records raw/final text, prompt, vocabulary, app context, screenshot information and optional audio. This supports debugging, but would retain much more sensitive context than Murmur needs by default. Keep recording retention, transcript retention and context retention independent. [Pipeline and recovery](https://github.com/zachlatta/freeflow/blob/ad5c827b5a324c503d58f948d500fa5d9f90e7d8/Sources/AppState.swift), [history fields](https://github.com/zachlatta/freeflow/blob/ad5c827b5a324c503d58f948d500fa5d9f90e7d8/Sources/PipelineHistoryItem.swift).

`AppContextService.swift` reads frontmost app metadata and Accessibility selection, captures the active window and can send its screenshot to a context model. That model produces a short activity summary before cleanup. This introduces another inference request, latency and data transfer. Borrow the principle of using app context as a spelling and formatting hint. Start with explicit app identity and user vocabulary; make screenshots a separate opt-in feature. [Context capture and inference](https://github.com/zachlatta/freeflow/blob/ad5c827b5a324c503d58f948d500fa5d9f90e7d8/Sources/AppContextService.swift).

### Inference and desktop details

STT is an OpenAI-compatible multipart endpoint with a configurable base URL, model and key, defaulting to Groq. Realtime transcription has a separate WebSocket implementation. Cleanup is another configurable endpoint call. No embedded Whisper, Parakeet or other local STT runtime was found in this source. A localhost-compatible URL is a server integration, not bundled local inference. [Batch STT](https://github.com/zachlatta/freeflow/blob/ad5c827b5a324c503d58f948d500fa5d9f90e7d8/Sources/TranscriptionService.swift), [realtime STT](https://github.com/zachlatta/freeflow/blob/ad5c827b5a324c503d58f948d500fa5d9f90e7d8/Sources/RealtimeTranscriptionService.swift).

The recorder independently produces a 16 kHz mono file for batch transcription and 24 kHz PCM16 chunks for realtime transport. That is a useful separation between canonical recording and provider stream format. It is audio capture/resampling, not evidence of denoising. Hotkeys use a macOS event tap; insertion snapshots clipboard contents and posts macOS key events. [Recorder](https://github.com/zachlatta/freeflow/blob/ad5c827b5a324c503d58f948d500fa5d9f90e7d8/Sources/AudioRecorder.swift), [global shortcut backend](https://github.com/zachlatta/freeflow/blob/ad5c827b5a324c503d58f948d500fa5d9f90e7d8/Sources/GlobalShortcutBackend.swift), [paste handling](https://github.com/zachlatta/freeflow/blob/ad5c827b5a324c503d58f948d500fa5d9f90e7d8/Sources/AppState.swift).

Two implementation choices should not be copied. Despite its filename, `KeychainStorage.swift` writes credentials to a JSON `.settings` file with mode 0600 and migrates old entries out of Keychain. Murmur should keep provider credentials in platform secure storage. The history store attempts recovery from a load error by deleting SQLite store files before retrying, which can destroy recoverable history. Preserve the original database and report recovery options instead. [Credential storage](https://github.com/zachlatta/freeflow/blob/ad5c827b5a324c503d58f948d500fa5d9f90e7d8/Sources/KeychainStorage.swift), [history recovery](https://github.com/zachlatta/freeflow/blob/ad5c827b5a324c503d58f948d500fa5d9f90e7d8/Sources/PipelineHistoryStore.swift).

No WPM analytics or managed billing implementation was found in the inspected Swift sources. Rate-limit cooldown handling is useful, but it is not spend accounting. Tests cover transcript parsing, shortcut state and cooldown logic; their presence is not a claim that they pass here. [Cooldown behavior](https://github.com/zachlatta/freeflow/blob/ad5c827b5a324c503d58f948d500fa5d9f90e7d8/Sources/LLMCooldownManager.swift), [transcript tests](https://github.com/zachlatta/freeflow/blob/ad5c827b5a324c503d58f948d500fa5d9f90e7d8/Tests/TranscriptTextCoreTests.swift).

Recommendation: borrow cleanup requirements and turn them into model-independent evaluation cases. Adopt raw fallback and separate command mode. Avoid the storage choices and automatic screenshot/context pipeline as defaults.

## Epicenter / Whispering

The current checkout has 3,571 tracked files and is a larger application platform, not only the older standalone Whispering app. The root license explicitly indexes apps and packages under AGPL-3.0-or-later. Any reuse decision must use this revision's license rather than an older recollection of Whispering's license. [License index](https://github.com/EpicenterHQ/epicenter/blob/20e9f3b4af6166c71484575c93a1047e95f157e4/LICENSE), [Whispering package](https://github.com/EpicenterHQ/epicenter/blob/20e9f3b4af6166c71484575c93a1047e95f157e4/apps/whispering/package.json).

### Separation worth studying

The Svelte app resolves browser and native-host services through platform imports. Recording, transcription, completion, delivery and persistence are separate operations. The pipeline creates a recording, saves raw transcription, runs optional Polish, stores polished text separately and delivers once. On cleanup failure or an explicit request to ship raw text, the transcript remains usable. That delivery order avoids inserting both raw and cleaned versions. [Service boundary](https://github.com/EpicenterHQ/epicenter/blob/20e9f3b4af6166c71484575c93a1047e95f157e4/apps/whispering/src/lib/services/index.ts), [pipeline](https://github.com/EpicenterHQ/epicenter/blob/20e9f3b4af6166c71484575c93a1047e95f157e4/apps/whispering/src/lib/operations/pipeline.ts), [Polish operation](https://github.com/EpicenterHQ/epicenter/blob/20e9f3b4af6166c71484575c93a1047e95f157e4/apps/whispering/src/lib/operations/run-polish.ts).

Polish has fixed meaning-preservation instructions wrapped around the user-editable directive. Dictionary injection is separate and also serves explicit transformation recipes. The ordinary cleanup operation supplies raw text and dictionary guidance; it does not collect screenshots or active-app content in this path. The UI exposes where STT and cleanup run independently. These are good product boundaries for local audio plus optional remote text cleanup. [Prompt composition](https://github.com/EpicenterHQ/epicenter/blob/20e9f3b4af6166c71484575c93a1047e95f157e4/apps/whispering/src/lib/operations/build-system-prompt.ts), [destination and capability state](https://github.com/EpicenterHQ/epicenter/blob/20e9f3b4af6166c71484575c93a1047e95f157e4/apps/whispering/src/lib/operations/run-polish.ts).

The STT catalog separates access through a provider key, an on-device engine, a custom endpoint and an authenticated managed session. Prompt/language support are capabilities rather than assumptions shared by all providers. Native local inference is currently `transcribe.cpp` with a curated GGUF catalog containing Whisper Tiny, Whisper Small and Parakeet v3. The host owns model residency, serialization and unload policy. Catalog model revisions are `main` strings at this pin, so copying the catalog would not give reproducible weight downloads. Murmur should pin model artifact revisions and checksums. [Provider catalog](https://github.com/EpicenterHQ/epicenter/blob/20e9f3b4af6166c71484575c93a1047e95f157e4/apps/whispering/src/lib/services/transcription/providers.ts), [native model catalog](https://github.com/EpicenterHQ/epicenter/blob/20e9f3b4af6166c71484575c93a1047e95f157e4/apps/epicenter/src-tauri/src/transcription/catalog.rs), [model cache](https://github.com/EpicenterHQ/epicenter/blob/20e9f3b4af6166c71484575c93a1047e95f157e4/apps/epicenter/src-tauri/src/transcription/model_cache.rs).

### Platform gaps

The desktop shell uses Tauri global shortcuts. Paste uses Enigo and Cmd+V on macOS or Ctrl+V on Windows/Linux. The macOS path watches actual Accessibility event-tap health rather than trusting the permission bit alone. Elsewhere the capability monitor is a stub. Linux terminal-specific Ctrl+Shift+V handling is absent from the inspected delivery function. It also restores only prior text on non-macOS platforms. These are direct reasons to replace delivery with platform-specific adapters for Murmur. [Native delivery](https://github.com/EpicenterHQ/epicenter/blob/20e9f3b4af6166c71484575c93a1047e95f157e4/apps/epicenter/src-tauri/src/delivery.rs), [permission monitor](https://github.com/EpicenterHQ/epicenter/blob/20e9f3b4af6166c71484575c93a1047e95f157e4/apps/epicenter/src-tauri/src/keyboard/mod.rs), [shortcut registration](https://github.com/EpicenterHQ/epicenter/blob/20e9f3b4af6166c71484575c93a1047e95f157e4/apps/epicenter/src-tauri/src/shell.rs).

The ordinary overlay is a 224 by 40 logical-pixel Tauri webview. macOS replaces it with a non-activating NSPanel. No comparable native Wayland layer-shell implementation was found in these overlay paths. Generic always-on-top, focusable and size flags do not prove Hyprland will handle the overlay correctly. Native mobile keyboard/IME support was not found; the platform type comments explicitly describe iOS as a web case. [Overlay window](https://github.com/EpicenterHQ/epicenter/blob/20e9f3b4af6166c71484575c93a1047e95f157e4/apps/whispering/src/lib/recording-overlay/window-manager.tauri.ts), [macOS panel](https://github.com/EpicenterHQ/epicenter/blob/20e9f3b4af6166c71484575c93a1047e95f157e4/apps/epicenter/src-tauri/src/overlay.rs), [platform types](https://github.com/EpicenterHQ/epicenter/blob/20e9f3b4af6166c71484575c93a1047e95f157e4/apps/whispering/src/lib/platform/types.ts).

### Hosted service and accounting

Unlike the OpenWhispr client checkout, Epicenter includes a server STT gateway and hosted billing policies. The shared transcription route fixes an upstream model and requests duration in the response. Deployment middleware supplies authentication and metering. The hosted policy uses server-owned provider credentials; direct BYOK is a separate client route. This is useful evidence for keeping the managed service optional. [STT gateway](https://github.com/EpicenterHQ/epicenter/blob/20e9f3b4af6166c71484575c93a1047e95f157e4/packages/server/src/routes/transcription.ts), [billing policies](https://github.com/EpicenterHQ/epicenter/blob/20e9f3b4af6166c71484575c93a1047e95f157e4/apps/api/worker/billing/policies.ts).

The hosted chat policy reserves credits before a request and confirms or releases them afterward. STT behaves differently: it checks for a non-empty balance and charges after receiving duration. The source explicitly acknowledges overspend from concurrent requests and long recordings. It also floors a successful call to a minimum credit charge if duration is missing. This is not an implementation to copy for strict user spending limits. Murmur needs admission limits, a conservative reservation, idempotent settlement and reconciliation with provider-reported usage. Its price display must separate an estimate from a settled charge. [Reservation and STT settlement](https://github.com/EpicenterHQ/epicenter/blob/20e9f3b4af6166c71484575c93a1047e95f157e4/apps/api/worker/billing/policies.ts), [credit catalog](https://github.com/EpicenterHQ/epicenter/blob/20e9f3b4af6166c71484575c93a1047e95f157e4/apps/api/worker/billing/catalog.ts).

No speech-WPM dashboard was found in the inspected Whispering application. Provider catalog price strings are advisory UI data, not a usage ledger or verified current vendor prices. Recommendation: independently implement the operation boundaries, recovery behavior and managed/direct-provider separation. Do not adopt the full workspace/sync platform solely to build dictation, and do not copy its AGPL implementation into a differently licensed project without deciding that explicitly.

### Cleanup and app integration

The cleanup contract preserves wording, meaning, certainty and tone, handles self-correction and treats transcript instructions as dictated text. It attaches custom vocabulary and optional selected text, clipboard text and extracted screen text in separate context sections. The prompt instructs the model not to copy unspoken context into the result. Cleanup can use cloud providers, an OpenAI-compatible custom service, Ollama, Local CLI or its own local Refine engine. ### Statistics and cost limits

VoiceInk stores `SessionMetric` separately from transcript history, with word count, audio duration, STT duration, engine, cleanup engine, cleanup duration and estimated cleanup tokens. Recording metrics deduplicate by transcription ID and require a completed session. The dashboard supports recent-seven-day and previous-seven-day windows, usage and performance breakdowns. This is a useful basis for keeping aggregate progress after transcript deletion. [Metric model](https://github.com/Beingpax/VoiceInk/blob/5fd71515089f54a2698cda8ec0013b9cd0b3e417/VoiceInk/Infrastructure/Persistence/Models/SessionMetric.swift), [metric recording](https://github.com/Beingpax/VoiceInk/blob/5fd71515089f54a2698cda8ec0013b9cd0b3e417/VoiceInk/Infrastructure/Persistence/Statistics/SessionMetricRecorder.swift), [dashboard periods](https://github.com/Beingpax/VoiceInk/blob/5fd71515089f54a2698cda8ec0013b9cd0b3e417/VoiceInk/Features/Dashboard/State/DashboardStatsModels.swift).

There are important semantic limits. Word count prefers enhanced output when available, so it measures produced text rather than strictly spoken words. The model `speedFactor` is audio duration divided by processing duration, not speaking WPM. Time saved assumes a 40-WPM typist. Cleanup tokens are estimated by dividing character count by four and rounding up; they are not provider usage. Murmur should name these metrics separately and never use that estimate for final charges. No explicit speaking-WPM calculation was found in the inspected sources. [Metric calculations](https://github.com/Beingpax/VoiceInk/blob/5fd71515089f54a2698cda8ec0013b9cd0b3e417/VoiceInk/Infrastructure/Persistence/Statistics/SessionMetricRecorder.swift), [time-saving assumption](https://github.com/Beingpax/VoiceInk/blob/5fd71515089f54a2698cda8ec0013b9cd0b3e417/VoiceInk/Features/Dashboard/State/DashboardStatsModels.swift), [token estimate](https://github.com/Beingpax/VoiceInk/blob/5fd71515089f54a2698cda8ec0013b9cd0b3e417/VoiceInk/Infrastructure/Persistence/Statistics/EstimatedTokenCounter.swift).

Recommendation: independently implement clipboard ownership and separate session metrics. Use its engine list to select experiments, then measure real hardware. Do not use its GPL code as an unexamined shortcut to a proprietary product or assume the same Apple runtime can serve Linux, Windows and Android.

## Decisions these sources support

1. Keep STT, transcript cleanup and acoustic processing separate. These projects mostly demonstrate text cleanup; a VAD, resampler or animated audio level is not a denoiser.
2. Make each job capture its STT route, cleanup route and context policy. A local STT choice must not silently authorize cloud cleanup or a cloud fallback.
3. Keep raw text recoverable under retention settings, and insert only the chosen final result. Cleanup failure should offer raw output without running another provider unexpectedly.
4. Store spoken words, delivered words, recording duration, processing latency and billing usage separately. Compute weekly speaking rate using summed covered words and summed covered duration, and show missing-duration coverage.
5. Design native delivery and overlays per platform. A small webview size, a cross-platform global-shortcut API and a Ctrl+V function are insufficient evidence for Hyprland support.
6. Treat iOS keyboard integration and Android IME integration as separate product work. OpenWhispr's implemented iOS keyboard does not close its Android gap.
7. Keep managed billing on the server. Reserve before admitted work, enforce per-user concurrency and duration caps, settle once and distinguish estimated provider cost, actual provider cost and the price charged to the user.

The next verification should use short dictation fixtures and actual target apps on each operating system. Prioritize Wayland-native editors and terminals, a compositor with XWayland disabled, mixed-DPI screens, focus changes during transcription, clipboard changes during restore delay, revoked macOS permissions, iOS host suspension and Android keyboard lifecycle changes. Source inspection can identify the contracts; only those runtime checks can establish the polished experience requested.
