# Licensing and reuse

Murmur's desktop application is a fork of Handy. Its implementation was copied from the pinned research checkout into [apps/desktop](../apps/desktop), then modified locally. The original MIT license and CJ Pais copyright notice are preserved in [apps/desktop/LICENSE](../apps/desktop/LICENSE). The other research checkouts remain ignored references. The repository has no top-level public distribution license yet; the desktop Cargo and bundle metadata currently declare MIT.

## Asset and nested-code obligations

Handy's MIT code license does not cover all of its branding. The [pinned README's license section](https://github.com/cjpais/Handy/blob/8f9cf53cd1410cda26beea39ff802ac306e39585/README.md#license) explicitly excludes the Handy name, logo, icon and brand assets from its open-source permissions and requires unofficial forks to use their own branding without implying affiliation. The copied branding has therefore been replaced separately from the MIT code.

The branding check on 26 September 2026 verified these changes:

- All 51 files inherited under `src-tauri/icons/` differ from the pinned upstream bytes. This includes PNG, ICO and ICNS files and the iOS and Android icon sets.
- All 10 retained resource PNGs differ from upstream. The copied `resources/handy.png` and `resources/handy_warning.png` files were removed, and the colored idle tray now uses `resources/murmur.png`.
- [generate-brand-assets.py](../apps/desktop/scripts/generate-brand-assets.py) draws Murmur's waveform from geometric primitives and writes the app and tray images. It does not load an upstream brand image as input. A rendered app icon was visually inspected.
- `src/components/icons/HandyHand.tsx` was removed. The [sidebar](../apps/desktop/src/components/Sidebar.tsx) uses Lucide's `AudioLines` icon, subject to the Lucide terms below. [HandyTextLogo.tsx](../apps/desktop/src/components/icons/HandyTextLogo.tsx) retains an inherited component name but contains a replacement Murmur waveform and wordmark; onboarding uses this same component.

These findings close the copied-image and hand-illustration issue in the application source tree. References to Handy as the code's origin and dependency/component identifiers remain provenance, not permission to reuse its branding. Packaged installers still need visual checks of icons, tray states and onboarding. The original assets remain available in the ignored research checkout for comparison. [Upstream icon inventory](https://github.com/cjpais/Handy/tree/8f9cf53cd1410cda26beea39ff802ac306e39585/src-tauri/icons), [upstream resource inventory](https://github.com/cjpais/Handy/tree/8f9cf53cd1410cda26beea39ff802ac306e39585/src-tauri/resources).

## Current decisions

| Group                       | Repositories                                                   | Treatment                                                                                                                                                                  |
| --------------------------- | -------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Imported application        | Handy                                                          | Desktop fork recorded above. MIT notice preserved and copied branding images replaced; nested code, dependency and model/sound obligations remain                          |
| Permissive donor candidates | OpenWhispr, Flow, FreeFlow, Yap, whispers, Voxtype, Dictus iOS | Their inspected root license is MIT. Preserve the applicable copyright and full permission notice with substantial reused code. Check file-level and dependency exceptions |
| Copyleft references         | Epicenter/Whispering, VocaPhone, VoiceInk                      | Epicenter is AGPL-3.0-or-later, VocaPhone declares AGPLv3, VoiceInk declares GPLv3. Keep as design references until choosing a compatible product/distribution approach    |
| Source-available references | FUTO Voice Input, FUTO Keyboard                                | Source First 1.0 and 1.1-kb respectively. Their modification/distribution conditions do not fit copying into the planned commercial product under those terms              |

Exact license files, revisions and file-level source links are in [core audit](research/core-repositories.md), [product audit](research/product-repositories.md), [additional audit](research/additional-repositories.md) and [the source lock](../research/sources.lock.json). MIT expressly permits commercial use and distribution with its notice conditions. [MIT terms](https://choosealicense.com/licenses/mit/)

GPL and AGPL are not blanket bans on charging money. They impose obligations when covered work is conveyed; AGPL additionally addresses modified covered programs used through a network. A separate service or API boundary is not automatic license clearance. The exact combined work, modifications and distribution determine the obligations. Read the actual pinned license text before importing code. The proposed permissive-first approach keeps the commercial product options open without making that licensing decision now.

Research into FreeFlow's cleanup behavior, OpenWhispr's provider and statistics designs, Epicenter's pipeline boundaries or VoiceInk's clipboard ownership informs product decisions. Those concepts are distinct from copying their source, prompts, assets or tests. Handy is the application implementation import recorded here. Any later import from another project needs its own record, even if it is only a prompt or a small utility. Do not describe copied or translated code as an independent implementation merely because it has different names or a different language.

The Linux modifier guard in [linux_modifier_guard.rs](../apps/desktop/src-tauri/src/linux_modifier_guard.rs) adapts the approach in [Voxtype's modifier guard at the pinned revision](https://github.com/peteonrails/voxtype/blob/9c35b72b4fa3635028dfe70b444ca0dc9dcfb389/src/output/modifier_guard.rs). It reads current evdev modifier state before Murmur injects text. The implementation was written for Murmur rather than copied as a file, but it is close enough in purpose and structure that the conservative treatment is to preserve Voxtype's MIT notice. [Voxtype-MIT.txt](../apps/desktop/src-tauri/resources/licenses/Voxtype-MIT.txt) is bundled with the desktop resources. The Wayland clipboard input change was informed by [whispers' injection code](https://github.com/OneNoted/whispers/blob/5f0763109f9dde6c780bd2ef50cbd22e310c28c3/src/inject/clipboard.rs); Murmur uses an unnamed temporary file and a bounded child process, with no source file imported. Its MIT notice is also bundled in [whispers-MIT.txt](../apps/desktop/src-tauri/resources/licenses/whispers-MIT.txt) for clear provenance. These notices do not resolve the separate model, sound, or dependency checks above.

## Record each implementation import

Before taking a file or substantial excerpt, record:

1. Upstream repository URL, full commit, path and original copyright.
2. Governing file/repository license and applicable dependency or vendored notices.
3. Destination in Murmur, changes made, and whether it is copied code or an independent implementation informed by documented behavior.
4. Required distribution notice/source offer and the validation performed after import.

Keep required third-party notices with the product. A link to GitHub alone is not a replacement for the full MIT permission notice. Do not delete author notices to meet the separate rule against tool/model attribution. Avoid copying unrelated upstream agent instructions or generated-attribution footers into authored material.

Models need a second record: original weights, conversion origin, revision, checksum, quantization, runtime and license. Whisper, Parakeet, Moonshine variants and Voxtral do not all share one license just because they are speech models. The same applies to local cleanup weights. See [model license findings](research/models-and-cleanup.md).

Use observable product ideas and independent assets. Do not copy Wispr Flow's trademark, logo, screenshots, marketing copy or proprietary implementation. Third-party store distribution claims are not proof that an API technique is approved; Dictus's private UIKit path is a concrete example of code that remains unsuitable even with a permissive copyright license.

Before a public release, produce a dependency/SBOM review for the actual shipped builds, include native helpers and model assets, decide Murmur's public license, and review store compatibility. A root-license table is a research filter, not a complete release clearance.
